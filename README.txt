FuelTrack — Food & Sports Planner

To publish with GitHub Pages:
1. Create or open a GitHub repository.
2. Upload index.html to the top/root level of the repository (not inside another folder).
3. Open the repository's Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish. The website URL will appear in Settings → Pages.

This is a single-file website. Open index.html locally to preview it. Progress is saved in that browser's local storage and does not automatically sync between devices.
